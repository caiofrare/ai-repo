# Setting Up Skills and Claude Code

This setup basically consists of Matt Pocock's skills, customized to fit my needs.

## How to use

1. Clone this repo
2. Run `/setup-matt-pocock-skills`
3. Delete this README.md
4. Start with `/grill-with-docs` and have fun!

## Suggested workflow

Idea
  → `/grill-with-docs`               (align + vocabulary)
  → `/to-spec`                       (spec in the tracker)
  → `/to-tickets`                    (break down into small tickets)
  → `/implement`                     (TDD + code review + commit)
  → `/improve-codebase-architecture` (run this once every few days to prevent your codebase from turning into a ball of mud)
